# Mini Social Network for Hobby Groups

🎨 This repository contains the Figma-based UI design for a Mini Social Network platform dedicated to hobby groups.

You can view the full UI prototype here:

👉 [Hobby Social Network Demo](https://www.figma.com/proto/TetCCUVtw0iynfepDUSIxT/c%E1%BB%A7a-Th%C6%B0%C6%A1ng?node-id=0-1&t=IffDWxbOeCJJLOvV-1)

## 📌 Overview

This project focuses on designing the user interface (UI) for a social networking application that allows users to:

- Connect through shared hobbies
- Create and manage groups
- Post, share, and comment on content
- Report inappropriate content
- Explore users, groups, and posts

---

## 🚧 Note

This repository includes only the UI design. There is no backend or frontend code implementation.
